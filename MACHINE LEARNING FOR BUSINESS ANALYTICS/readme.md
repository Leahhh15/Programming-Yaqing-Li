# R Data Analysis & Machine Learning Portfolio

A collection of R assignments and lab exercises covering data handling, data cleaning, statistical summarization, and machine learning models including Naïve Bayes, k-NN, decision trees, random forests, and neural networks.

## Contents

- R Basics
- Data Frames and Missing Values
- Data Cleaning and Summarization
- Naïve Bayes (Titanic, Flight Delays)
- k-NN (Iris Classification, Auto-MPG Regression)
- Decision Trees and Random Forest (eBay Auctions)
- Neural Networks (Iris, Boston Housing, Bank Marketing)

## Datasets

| Dataset | Source |
|---|---|
| `titanic_hw_new.csv` | Course-provided |
| `FlightDelays.csv` | Course-provided |
| `eBayAuctions.csv` | Course-provided |
| `auto-mpg.csv` | UCI |
| `bank_marketing_new.csv` | UCI |
| `iris`, `mtcars` | R built-in |
| `Boston` | `MASS` package |

## Skills

- R programming and data structures
- Data cleaning and missing value imputation
- Exploratory data analysis and summary statistics
- Classification: Naïve Bayes, k-NN, decision trees, random forest, neural networks
- Regression: k-NN regression, neural networks
- Model evaluation: confusion matrix, accuracy, ROC/AUC, lift chart, RMSE
- Reproducible analysis with `set.seed()`
