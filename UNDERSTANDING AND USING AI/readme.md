# Understanding and Using AI

Course portfolio for *Understanding and Using AI*, covering neural network
implementations from scratch using NumPy — from the perceptron to
backpropagation and modern optimizers — plus applied classification tasks
and a transfer learning project.

## Highlights
- Built MLP and CNN-ready layers from scratch (no deep learning frameworks)
- Implemented backpropagation manually (Affine, ReLU, Softmax)
- Compared SGD / Momentum / AdaGrad / Adam / RMSprop
- Studied weight initialization and Batch Normalization effects
- Applied models to real datasets: Iris, Wine, CIFAR-100
- Fine-tuned a pretrained ResNet18 for image classification (transfer learning)
